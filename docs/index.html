Private by design.

Hop has no backend at all. Your phone talks straight to your Mac, and nothing else is listening.

No cloud, no relay

Devices find each other with Bonjour on your local network. If they aren't on the same Wi-Fi, nothing is sent.

Encrypted end to end

Each connection derives a fresh key and encrypts every frame with AES-256-GCM. Frame counters stop anything being replayed or reordered.

Only the code leaves

From your texts and notifications, Hop extracts the code (and the sender's name). The message itself never leaves your phone.

No accounts, no analytics

No sign-up, no tracking, no crash reporting. Hop doesn't know who you are, and doesn't want to.

Paired by you

A random 32-byte key, shared once by QR code. Unpair from the Mac anytime and the old key stops working immediately.

Open source

Every line is on GitHub under the MIT license, including the wire protocol spec. Read it, build it yourself, or fork it.

Frequently asked questions

Still curious? Open an issue on GitHub.

How do I install it?

Download both apps below. On the Mac, unzip and move Hop.app to Applications, then right-click → Open the first time (it isn't notarized yet). On the phone, open the APK and allow installs from your browser. If Play Protect says it's harmful (it flags every app that reads SMS from outside the Play Store), tap More details → Install anyway, or install over USB with adb install Hop-android.apk. Then choose Pair Phone… in Hop's menu bar and scan the code with the phone.

Why does it need to read my SMS?

Android 15 and later hide one-time codes inside notifications from other apps, so reading incoming texts is the only reliable way to catch bank codes. Hop looks only for the code, and only the code is sent to your Mac.

What do I need for phone screen mirroring?

Install the tools once with brew install scrcpy and turn on USB debugging on your phone. Plug in once, and after that Hop mirrors over Wi-Fi until the phone restarts.

Do both devices need to be on the same Wi-Fi?

Yes. That's what keeps everything off the internet. Some guest and hotel networks block devices from seeing each other, so Hop won't connect there.

Does it work with phones other than Samsung?

Yes, with any Android 12+ phone. The phone-shaped mirroring window is styled after a Galaxy, but everything else uses standard Android features.

Is it really free?

Yes. Hop is open source under the MIT license, with no paid tier, no ads and no accounts.
